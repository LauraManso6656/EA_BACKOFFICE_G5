# Univy Backoffice (EA_BACKOFFICE_G5)

Panel de administración y backoffice de **Univy** desarrollado con Angular (v21) y TypeScript.

## 🛠️ Tecnologías principales
- **Angular 21** + **TypeScript**
- **Angular SSR** (Server-Side Rendering)
- **RxJS** (Programación reactiva)
- **Express** (Servidor SSR)

## 🚀 Desarrollo y Ejecución

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Ejecutar en desarrollo:**
   ```bash
   npm run start
   ```
   *El servidor de desarrollo estará disponible en `http://localhost:4200/`.*

3. **Construir para producción:**
   ```bash
   npm run build
   ```

## 🧪 Comandos adicionales
- `npm run test` - Ejecutar pruebas unitarias.
- `npm run watch` - Construir y vigilar cambios en desarrollo.
